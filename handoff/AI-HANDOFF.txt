3. build.py
-----------
Run from the repo root:   python3 handoff/build.py .      (stdlib only, Python 3)
- Reads the EXISTING terms/index.html and privacy/index.html to reuse their legal body, applies the FIX list, re-wraps them.
- Everything visible is written as t("Mongolian", "English"). t() returns the Mongolian text and records the pair in EN,
  which becomes assets/en.js. To add a game: append to GAMES (slug = short address, old, name, pid, uid, img, tag, mn, en)
  and add its image. t() stops the build if the same Mongolian text gets two different English translations.
- V = asset version. It is appended as ?v=V to app.css / app.js / en.js. CHANGE V whenever those files change,
  otherwise phones keep the old cached files.
- <html data-uids="..."> lists the universe ids; app.js uses them for the live numbers (no extra request needed).
- Rule for translations: app.js swaps whole text nodes by exact trimmed match, so every translatable string must be its own text
  node (no inline <b>/<a> inside a sentence). Use separate <span>s when needed.

4. assets/app.js  (one shared script, no dependencies)
-------------------------------------------------------
Language: Mongolian is the default. EN only when localStorage "eg-lang"==="en" (set by the #lang button). Elements with data-nt are skipped.
Live data (all through the Worker, section 6), one scheduler "tick":
  every 10 s while the tab is visible: GET /groups/v1/groups/35654822 (members) + GET /games/v1/games?universeIds=<data-uids>
  on errors: retry after 10, 20, 40, 60 s; paused while the tab is hidden; runs again on "online".
  Each request: 8 s timeout, redirect:'manual' (a redirect means Cloudflare Access is blocking the Worker; a console warning says so).
  #lst/#lsm status line: "Шууд · HH:MM:SS-д шинэчлэгдсэн" / error text. Shown on the home page and every game page.
  #sm members, #sp total playing, #sv total visits.
  li[data-p=PLACEID] cards: every .pl (card text + image pill) = playing, .vs visits, .fv favorites; .lv and .pill are hidden until data arrives;
  card gets class "hot" when someone is playing.
  main[data-page=PLACEID] on game pages: [data-g=playing|visits|fav|updated] + the image pill.
  #uw/#ul "recently updated" list; game names come from the site's own card titles (Roblox names contain emoji like [🎃]).
  Numbers tween and flash (.bump) when they change.
Images: .shot wrappers; if an image fails, .shot gets class "noimg" and shows the logo instead of a broken image.
Team avatars: [data-uid=<user id>] -> ONE thumbnails request for the whole team; cached 24h in localStorage "av3:<id>"; falls back to the letter.
All requests go through J(): timeout, no cookies, Worker redirects treated as "blocked".
News: fetches news.json (fields: date, tag, game, title, text, link, linkText + *_en variants); #nl list, #ne empty-state text.
ID card (index): #idf form, #idn input, #ids status, #ido output, #idc canvas 1000x560, #idsave, #idshare. Labels on the card are English on purpose.
Game pages: #sh share-link button (navigator.share or clipboard) and #shn message.
Animations: .rv elements fade/slide in once via IntersectionObserver with stagger (--i); h2.in grows the three-bar underline.
Copy/save protection (best effort): CSS user-select:none except .sel, img pointer-events:none; JS blocks contextmenu except on a/.sel/input.
localStorage keys: eg-lang, av3:<user id>, eg-404 (404 game best score). No cookies, no analytics.

-------------------------------------------------------------------------------------------------------------
!!! The workers.dev address MUST be public. In Nov 2026 the live numbers were broken because Cloudflare Access was turned on
    for eegs.e05729613.workers.dev: every request got a 302 redirect to e05729613.cloudflareaccess.com (a login page).
    Fix: Workers & Pages -> eegs -> Settings -> Domains & Routes -> workers.dev -> turn OFF Cloudflare Access
    (or Zero Trust -> Access -> Applications -> delete the application for eegs.e05729613.workers.dev).
    Check: open https://eegs.e05729613.workers.dev/groups/v1/groups/35654822 in a private window: you must see JSON, not a login page.
URL scheme:  https://<worker>/<service>/<roblox path>   service = games | groups | users | thumbnails
  GET  /games/v2/groups/{id}/games            GET /games/v1/games?universeIds=1,2,3     GET /groups/v1/groups/{id}
  GET  /groups/v1/users/{userId}/groups/roles GET /users/v1/users/{userId}
  GET  /thumbnails/v1/users/avatar-headshot?userIds={id}           (150x150 Png forced)
  GET  /thumbnails/v1/games/multiget/thumbnails?universeIds=1,2,3  (768x432 Webp, not used by the site yet)
  POST /users/v1/usernames/users  body {"usernames":["Name"]}      (^[A-Za-z0-9_]{3,20}$, excludeBannedUsers forced)
  GET  /img?u=<https://*.rbxcdn.com/...>      GET /health
  Everything else -> 404. CORS is allowed for https://eegs.blog, https://www.eegs.blog and http://localhost (testing).
  Cache: 5 s for live counts, 60 s for the game list, 300 s for users/avatars/roles, 3600 s for images.
Never put API keys in front-end code. If an Open Cloud key is ever needed, store it as a Worker secret.
